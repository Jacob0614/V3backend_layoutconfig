# V3後台原型-前端自定義配置

本目錄是本次唯一可寫入的實作目錄。原型以 V3 後台既有的頂部導航、內容區、麵包屑、配置中心分頁與 Naive UI 控件為框架，在「配置中心／系統配置」下新增「版面配置」功能頁，不建立另一套後台。

## 使用入口

啟動開發伺服器後開啟：

`http://127.0.0.1:4173/index.html#/config-center/layoutConfig`

操作鏈路：商戶清單 → 指定商戶 → 選設備端 → 版面設定 → 配置首頁模組 → 預覽／保存。

## 已實作流程

- 商戶清單只顯示已授權商戶；每列提供新增、編輯或繼續編輯，已發布版本與草稿狀態分開顯示。點擊「新增自訂義版面」後先選目標商戶與設備端，再進入該設備端的模板與模組配置。
- 有草稿時進入編輯會提示「繼續編輯草稿」或「捨棄草稿後建立新草稿」；捨棄為永久捨棄草稿，重新載入清單後仍維持無草稿。
- 沒有已發布版本的商戶，新增時從空白頁開始；選擇模板後立即載入模板預設模組。
- 已有發布版本且沒有草稿時，編輯會從該商戶 mock 資料的已發布模板開始；正式整合時由 V3 已發布配置 API 提供完整配置快照。
- 首頁目前分為 PC、H5、Android、iOS、RWA 五個設備端。Android／iOS／RWA 均使用 APP 設備規格 375×812，H5 使用行動版規格 375×812；PC 依桌面版規格配置。
- 模板依實際來源標示可用設備端；第一期完成後仍可持續新增模板，不將模板清單視為一次性完成。
- 編輯頁採分步驟精靈：先選設備端，再在版面設定選模板、主題與底部導航；按「下一步」後才進入配置首頁模組。配置首頁模組階段只顯示模組庫與模組設定，不顯示版面設定。
- 三端配置與保存完全獨立；模板與主題只套用目前設備端。未完成項目仍可保存草稿，只有必要配置完成且預覽成功才可送審。
- 已建立實際首頁根元件模板並標注站點編號；`public5WhiteGreenHome`（AR095）與 `public7Home`（AR093）已核對來源，實際可用設備端依模板來源標記。
- 模組庫依第一層模組分類展示；點選分類後先進入該模組的形式選擇，以下方縮圖選擇具體形式，再加入畫布並進入模組設定。畫布只保留移除操作，排序在模組設定內完成。
- 首頁不設「未配置內容」區。移除模組後回到模組庫；模板切換後無法對應的既有模組仍保留在目前畫布並標示為自定義模板，不靜默刪除。
- Banner僅配置首頁模組與展示方式，活動內容由活動配置提供；刪除 Banner 模組後回到模組庫，依已確認比例等比縮放。
- 遊戲模組只引用既有遊戲配置；遊戲圖片尺寸在模板規則中使用 222×300 比例等比縮放，三端共用遊戲配置。
- 浮標入口清單與路由固定，只能配置圖標、排序及展示頁；展示頁依終端分開，以一級／二級頁樹狀勾選。
- 低保真畫布只展示功能區、色塊、圖標與必要位置，不展示補充說明文案；預覽才展示完整內容。預覽依設備基準尺寸等比縮小，使用對應設備外框並填滿展示區。
- 複製其他終端配置時，衝突逐項選擇來源或目前內容；中途取消會全部還原。
- 編輯中切換設備端只處理離開中的設備端；返回商戶清單或離開頁面時，若任一設備端有未保存變更，統一提示保存全部草稿／捨棄全部變更／關閉提示。
- 單筆套用依「來源商戶／設備端／該端已發布版本」執行；目標設備端已有草稿時保留原草稿並禁止覆蓋。
- 批量操作以商戶與設備端分別建立草稿交接資料；既有草稿不覆蓋，重新整理後仍可繼續編輯。
- 發布失敗不替換前台穩定版本；版本抽屜記錄前台維持前一版本、失敗原因、失敗時間與重試次數。
- 已發布版面列提供直接修改共用版面入口；修改前顯示設備端與所有引用商戶，修改會建立共用版面草稿，必須送審並發布後才同步引用端。

## 主要檔案

- `src/layout/AppLayout.vue`：V3 後台框架與頂部導航。
- `src/router/index.ts`：配置中心「版面配置」分頁、功能頁與編輯頁路由；舊 `frontendCustom` 路徑保留導向。
- `src/views/config/frontendCustom/MerchantList.vue`：商戶清單、新增／編輯入口與草稿處理。
- `src/views/config/frontendCustom/index.vue`：首頁模板、模組畫布、三終端、預覽、版本與送審流程。
- `src/views/config/frontendCustom/draftState.ts`：原型用瀏覽器本地草稿狀態，沒有連接真實 API。
- `src/styles.css`：V3 工作台與首頁配置畫布樣式。

## 限制

- 不修改 `source-materials/current-product`。
- 不修改 `source-materials/new-backend`。
- 本版本不連接真實 API；資料、版本、審批與草稿狀態均為原型行為。
- 其他前台頁面維持現行內容；其他後台頁面只保留 V3 框架入口，不做本次功能以外的交互。
